Build from Source or Publish an Update

1. Run Directly from Source

Clone the repository, activate the virtual environment, run database migrations, and launch the studio: 

git clone https://github.com/your-org/youtube-automation-studio.git
cd youtube-automation-studio
python3 -m venv .venv && .venv/bin/pip install -e .
.venv/bin/alembic upgrade head
.venv/bin/youtube-studio

2. Ship a New App Update

Build native macOS/Windows bundles and publish a new version to website/releases.json so connected clients receive update notifications automatically: 

# Build native bundle
./packaging/build_macos.sh

# Clients check Settings → Check for Updates
# against website/releases.json
